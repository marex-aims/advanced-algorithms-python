# Senegal temperature analyzer

An introductory notebook project for loading temperature observations, summarizing them, and comparing cities.

Open [`main.ipynb`](main.ipynb) in Jupyter or a compatible editor and run the cells in order. It starts with a small sample dataset; the next exercise is to move the data into `data/temperatures.csv` and read it from there.

The project is a learning scaffold. Input validation, a fuller dataset, and automated tests are still to be added.
