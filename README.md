# Advanced Algorithms in Python

A structured learning repository for implementing and studying algorithms in Python, from programming foundations to advanced algorithmic methods, numerical computing, optimization, and algorithmic machine learning.

This work accompanies my **Master’s studies in Mathematical Sciences at AIMS Senegal**. It combines course foundations with independent implementations, mathematical analysis, experiments, and applied projects. The repository is a work in progress; some sections are still placeholders.

## Repository map

| Path | Contents |
| --- | --- |
| `00_course_foundations/` | Python, Linux, Git, and small introductory projects |
| `01_algorithmic_foundations/` | Complexity, recursion, searching, and sorting |

| `challenges/`, `projects/` | Practice problems and applied projects |
| `references/` | Books, courses, papers, and useful links |
| `tests/` | Test suite (currently scaffolded) |

## Getting started

The introductory Python lessons are Jupyter notebooks in `00_course_foundations/python_basics/`. Open a notebook in Jupyter or a compatible editor and run its cells in order. The notebooks use only the Python standard library.

Other algorithm examples elsewhere in the repository are standalone Python files; check each example's source for its inputs and behavior.

The repository-wide test files and development configuration are not set up yet.

## GitHub configuration

The `.github/` directory contains settings and automation for GitHub. Workflow files belong in `.github/workflows/` and run in response to events such as pushes and pull requests. This repository currently has three empty workflow placeholders (`tests.yml`, `lint.yml`, and `benchmarks.yml`), so no automated checks or benchmarks run yet.
